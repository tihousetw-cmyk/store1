# 貼上文字，自動新增 Google Calendar 活動

這個工具讓你用自然語言描述活動（中文或英文皆可），AI 自動解析時間與地點，直接新增到你的 Google 行事曆。

**完全不需要安裝任何軟體，只需要瀏覽器。**

---

## 你需要準備的東西

1. **Google 帳號**（你已經有了，因為你要用 Google 行事曆）
2. **Anthropic API Key**（AI 解析文字用，免費申請）

---

## 第一步：申請 Anthropic API Key

1. 用瀏覽器開啟：**https://console.anthropic.com/**
2. 點右上角「Sign Up」，用 Google 帳號或 Email 註冊
3. 登入後，點左側選單「**API Keys**」
4. 點「**Create Key**」按鈕
5. 幫 Key 取個名字（例如「行事曆工具」），點「Create Key」
6. 把出現的 Key（長串英文字，`sk-ant-` 開頭）**複製起來備用**

   ⚠️ 這個 Key 只會顯示一次，請立刻複製並儲存到安全的地方（例如記事本）。

---

## 第二步：建立 Google Apps Script 專案

1. 用瀏覽器開啟：**https://script.google.com/**
2. 點左上角「**+ 新增專案**」

   你會看到一個編輯器，左側顯示「Code.gs」檔案。

---

## 第三步：貼入程式碼

### 貼入 `Code.gs`

1. 在左側看到「Code.gs」，點一下它
2. 把編輯器裡面**所有內容全部選取並刪除**（Ctrl+A 然後 Delete）
3. 開啟本專案的 `Code.gs` 檔案，**複製全部內容**
4. 貼入編輯器

### 新增 `index.html`

1. 點左側「檔案」旁邊的「**+**」號
2. 選「**HTML**」
3. 檔案名稱輸入：`index`（不需要加 `.html`，系統會自動加）
4. 把編輯器裡面預設內容全部刪除
5. 開啟本專案的 `index.html` 檔案，**複製全部內容**
6. 貼入編輯器

完成後，點上方**磁碟圖示**（或按 Ctrl+S）儲存。

---

## 第四步：設定 API Key

1. 點上方選單「**專案設定**」（齒輪圖示 ⚙）
2. 往下捲動，找到「**指令碼屬性**」區塊
3. 點「**新增屬性**」
4. 填入：
   - **屬性**：`ANTHROPIC_API_KEY`
   - **值**：貼上你在第一步複製的 API Key（`sk-ant-` 開頭）
5. 點「**儲存指令碼屬性**」

---

## 第五步：部署為網路應用程式

1. 回到編輯器，點右上角「**部署**」→「**新增部署作業**」
2. 點「類型」旁邊的齒輪圖示 ⚙，選「**網路應用程式**」
3. 設定如下：
   - **說明**：行事曆工具（隨便填）
   - **執行身分**：「**我**」
   - **誰可以存取**：「**僅限我自己**」
4. 點「**部署**」
5. 第一次部署時會跳出「授權存取」畫面：
   - 點「**授權存取**」
   - 選你的 Google 帳號
   - 如果出現「Google 尚未驗證此應用程式」警告：點「**進階**」→「**前往『（你的專案名稱）』(不安全)**」
   - 點「**允許**」

   ⚠️ 這個警告是因為你自己寫的程式沒有經過 Google 官方驗證，但由於你就是這個程式的作者，這是安全的。

6. 部署成功後，**複製「網路應用程式 URL」**（長串網址，以 `https://script.google.com/macros/s/` 開頭）
7. 把這個網址**加入瀏覽器書籤**

---

## 使用方法

1. 開啟剛才書籤的網址
2. 在輸入框貼上或輸入活動描述，例如：
   - `明天下午兩點在台北車站附近吃午餐`
   - `下週五下午三點開會，約一個半小時`
   - `5/1 上午十點線上會議`
3. 點「**解析並新增到行事曆**」按鈕（或按 Ctrl+Enter）
4. 幾秒後就會看到成功訊息，活動已新增到你的 Google 行事曆！

---

## 常見問題

### 出現「尚未設定 ANTHROPIC_API_KEY」

→ 請重新確認第四步，確認屬性名稱拼寫正確（區分大小寫）。

### 出現「Claude API 回傳錯誤（HTTP 401）」

→ API Key 不正確，請重新複製並貼上。

### 出現「資訊不足」

→ 你的描述中缺少具體的日期或時間，請補充後重試。例如「吃飯」就需要加上「明天中午十二點吃飯」。

### 第一次使用時需要「重新授權」

→ 這是正常現象。每次修改程式碼後重新部署，都需要重新授權。

### 我更新了程式碼，效果沒有改變

→ 更新程式碼後需要重新部署：點「部署」→「管理部署作業」→ 點鉛筆圖示 ✏️ → 版本選「新版本」→「部署」。

- 程式碼運行在你自己的 Google 帳號下，只有你能存取
